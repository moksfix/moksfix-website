# MoksFix Blog — Topic Backlog & Process

The scheduled draft task picks the **next unused topic** from the list below,
writes a genuinely useful ~600–900 word article, and stages it for review.

## How a new post is added (the process)
1. Pick the first topic under "Queued" that isn't already published.
2. Create `blog/drafts/<slug>.html` by copying the structure of an existing
   post (`how-much-does-a-website-cost-in-coimbatore.html`) — keep the GA tag,
   canonical, BlogPosting + BreadcrumbList schema, internal links and CTA.
3. Notify the user. After approval: move the file from `blog/drafts/` to `blog/`,
   add a card inside the `<!-- BLOG_CARDS_START -->` markers in `blog/index.html`,
   add the URL to `sitemap.xml`, then deploy.
4. Move the topic from "Queued" to "Published" below.

## Rules
- Genuinely useful, original content only — no thin/duplicate posts (Google's
  scaled-content-abuse policy). Quality over quantity.
- Each post targets ONE real search query, mentions Coimbatore/Tamil Nadu
  naturally, links to a relevant landing page + the contact section.
- Keep the same tone as the site: clear, confident, helpful, no fluff.
